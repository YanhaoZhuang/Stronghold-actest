# 快进联防 1.0.0

需要 Stronghold-Protocol 0.3.1 定制核心补丁，基线 c9d804f470b8d7422ae04eb66faf671cef21ad52，插件 API 2。
只安装 ZIP 到原版服务器不可用，原版会报告 PLUGIN_RULES。

在房间玩法插件中启用后，真人协防者全票同意可快速模拟至结束。
沿用原版击杀、漏怪归属、LP 上限及悬赏。AI 不投票，断线不视为同意。
15 秒超时或失败恢复正常战斗。不能与 script/trusted 插件同时启用。
取消房间的插件选择即可关闭功能；不修改已开局房间。

本插件不含脚本与游戏素材，permissions 为空。完整部署步骤见配套部署说明。
